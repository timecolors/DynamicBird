# ShoreHue 海岸线 — 版本发布说明

> 版本号遵循 x.y.z 语义化版本。本文件记录各版本新增功能与改进。

---


## v1.1.0（最新版本）

> 品牌焕新：**灵动鸟 DynamicBird → ShoreHue 海岸线**。产品名、代码、数据目录全面更名（旧配置数据已清理，不做自动迁移）。界面同时移除全部 emoji 图标，改用文字与矢量图标。

### 新品牌
- **ShoreHue 海岸线**：Shore（岸）+ Hue（色彩）——桌面边缘即海岸，岸上、岸下都丰富多彩，色彩随潮汐而动
- 编程生态「鸟笼」更名为 **海床**：文件夹即真相源的编程模式不变，功能像种子一样种进海床、自动生长
- 在线市场动语更新：发布功能 = **放流**（放流入海），安装功能 = **拾贝**（岸上拾贝）；界面不再使用吉祥物表情

### 新功能

**1. 海床：完全编程 / 完全编译（XAML + 代码后置）**
- 小组件与面板功能支持**完整 WPF 用户控件**：.xaml 界面 + .xaml.cs 代码后置，事件、绑定、样式全部可用——不再只是纯 C# 拼控件
- **VS Code 式双编辑器**：.xaml / .xaml.cs Tab 切换，底部**实时预览**；保存即编译，报错内联显示
- 编程模式区分：**简单编程**（纯 C#，快速原型）与**完全编程**（XAML 形态，完整控件）；AI 提示词按所选模式生成
- **海床 = 内置文件资源管理器**：树 = seabed 文件夹的真实目录扫描；点文件读真文件、编辑保存写回、删除走回收站；外部改动保存前提示覆盖，IO 失败重试不静默
- **文件夹即真相源强化**：小组件 XAML / 面板 main.cs / 状态栏配置全部直接从 seabed 文件夹读取真实内容
- **海床市场多形态协议**：功能包支持 manifest 文件清单 + 多文件上传/下载，按分类落盘，预览标注格式；五个内置小组件包更新为 XAML 形态

**2. 数字环（键盘呼出 16 区域）**
- 设置 → 区域 → 高级开启后，按**修饰键 + 数字 1-9**（主键盘或小键盘均可）直接呼出对应区域面板：7/9/1/3 四角、2/4/6/8 四边中段
- 精修组合：边键 + 邻角键（如 4+7 = 左边缘上段小组件）呼出**边端段**面板；再按一次收起
- 修饰键可改（默认 Ctrl，可选 Ctrl+Shift / Alt / Ctrl+Alt）；右上角默认安全区不呼出
- 键盘呼出的面板**钉住不自动隐藏**，配合「跟随鼠标/固定贴边」使用

**3. 其他新功能与改进**
- **界面字号缩放全局生效**：设置 → 面板 → 外观的字号滑块（75%~150%）现在对**桌面各面板**（任务栏 / 小组件 / AI 等）即时生效，不只是设置窗口
- **媒体控制修正**：上一首 / 下一首图标方向改正；移除底部冗余的「系统媒体键兜底」横条，界面更干净
- **设置窗口可拖拽调整大小**恢复（含左下角），原生窗口缩放边框重新启用

### 稳定性与体验改进
- **海床 watcher 重构**：按 VS Code 风格时间窗口聚合文件事件，事件合并不丢失、不再卡死；移除旧的 800ms 丢弃式防抖
- 应用图标改版：海蓝→沙滩 45° 渐变 + 透明二维码（icon.ico / MSIX logos / Store 图全部同步重生成）

## v1.0.5

> 本版聚焦「AI 编程生态」：**状态栏插件 + 自定义动画代码化**，让 AI 与用户一起为 ShoreHue「长出」新功能。

### 新功能

**1. 状态栏插件（AI 可编程）**
- 新增 `IStatusProvider` 接口：AI 生成 C#（如 CPU 温度、网速、股票）放入 `seabed\状态栏\` 自动编译挂载到状态栏
- 状态栏插件有独立开关、默认启用，卸载自动释放资源

**2. 自定义动画（AI 可编程）**
- 新增 `IAnimation` 接口：AI 生成 C#（如弹跳、翻转、粒子）放入 `seabed\动画\` 后可在设置中选作呼出/隐藏动画
- 动画执行带三重保护：异常回退内置动画、超时强制完成、完成回调幂等——杜绝卡死

**3. 全局界面字号缩放**
- 设置 → 面板 → 外观：字号滑块（75%~150%），所有界面即时生效

**4. 海床增强**
- 「AI 编程指南」按钮：打开完整 AI 编程教程（能做什么/不能做什么/各类格式）
- 「打开文件夹」：一键定位节点在 seabed 的位置；未选中节点时打开海床根目录
- AI 提示词按节点类型特化（状态栏/动画/面板/配置各生成对应接口模板）

### 稳定性与体验改进

- **性能优化**：面板切换/激活不再全量重编译插件（按签名守卫 + 沙箱结果缓存），触发面板更流畅
- **海床文件夹同步**：watcher 只监听文件增删，应用自身写盘不再触发事件链；放入 .dbp/.cs 自动识别
- **动画类型与状态栏插件**不再误入小组件标签
- **双箭头光标**：两处全局光标覆盖改为局部，鼠标移到设置窗口不再残留
- **动画保护期**：滑入滑出不被渲染帧跟随瞬间化
- 「区域」「面板」页签图标恢复；打开文件夹改用 explorer.exe 更可靠

## v1.0.4

> 本版聚焦「面板体验与生态」：设置页全面重构、交互竖条、在线市场、逐区域动画。

### 新功能

**1. 设置页 UI 重构**
- 页签按**作用对象**分类：常规 / 区域 / 面板 / 动画 / AI / 海床
- 任务栏与小组件统一归入「面板」设置（两者本质都是面板内容）；区域设置合并触发、面板类型、防误触与高级项
- 新页签与分节标题全部本地化（中英双语）

**2. 左侧交互竖条（取代主图标）**
- 主图标区域改为整条热区：**右键菜单按当前面板提供专属操作**——任务栏可显示桌面 / 清空运行中窗口 / 刷新，小组件直达海床，AI 直达 AI 设置
- 支持拖入快捷方式固定、拖窗口固定、拖快捷方式删除；hover 显示反馈条
- 竖条与内容区之间可拖动调整宽度（隐形分隔线），面板外边缘仍可拖动调整大小

**3. 在线市场**
- 预设/功能包托管于 GitHub 仓库（jsDelivr CDN 分发），客户端浏览 + 一键下载安装
- 安装链路：重新检测权限 → 风险弹窗确认 → 沙箱编译拦截危险 API
- 包随主仓库发布，**CI 自动编译验证**每个包，贡献者提交即可获得质量保障

**4. 逐区域动画**
- 16 个区域（四边 + 四角）可独立设置触发/隐藏动画类型与时长，或继承全局

**5. 其他**
- 面板运行帧率设置（自动 / 30 / 60 / 90 / 120 fps）
- 卸载功能（设置 → 通用）：二次确认，可选删除本地数据
- 按住 Ctrl 穿透时面板完全隐藏，下层内容 100% 可见可操作
## v1.0.3

> 本版聚焦「可编程化」：**海床（编程模式）全面完善**，配合已有的自定义小组件/动画设置/风格适配。

### 新功能

**1. 自定义小组件（C# 动态编译）**
- 内置 5 个可复用小组件模板：计时器、计算器、划词翻译、剪贴板、便签
- 保存为变体后可独立修改，编译后自动出现在小组件标签
- 内置编辑器已移除，改为到「海床」页统一编辑

**2. 海床（编程模式）— 本版重点**
- **配置即代码**：整个设置模型（面板设计/动画/外观/交互/状态栏，30+ 叶子节点）以配置树呈现，每个节点可生成/编辑可执行 C# 配置代码
- **单预设闭环**：保存当前预设（自动命名）→ 应用时编译执行写回生效 → 冲突的内置设置自动变灰（可两击解除单处覆盖、重新应用恢复）
- **整套预设**：全量配置快照保存/应用/删除，冲突标记与单预设统一
- **覆盖可见**：被预设覆盖的设置页变灰 + 海床树删除线 + 预设列表高亮，三处联动
- **面板功能源码化**：通知坞、最近使用、快捷设置提供完整纯代码模板；任务栏、AI 助手、窗口控制提供薄封装模板（复用内置视图，可外层自定义）——保存为面板变体后可分配到任意区域
- **复制 AI 提示词**：描述需求 → AI 生成 C# → 粘贴 → 编译 → 应用
- **其他海床共享平台**：导出 .dbp 预设包（导出时刻自动检测联网/剪贴板/文件/进程/系统/窗口/屏幕等权限并标注），导入时展示风险权限、确认后写入

**3. 动画设置**
- 触发/隐藏动画分设：滑入滑出、淡入淡出、缩放、弹性，独立时长与特化参数
- 面板从对应边缘滑入滑出，时长与缓动全部可调

**4. Windows 11 风格适配**
- Mica 毛玻璃背景、原生圆角、深色标题栏

### 修复
- 修复剪贴板小组件模板缺失列表刷新方法（模板现可正常编译）
- 清理海床页调试日志

### 安装
- Microsoft Store：搜索「ShoreHue 海岸线」
- GitHub Releases：下载 win-x64 单文件
